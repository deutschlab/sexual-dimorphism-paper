This repository contains code associated with the paper “Sexually dimorphic neurons in the Drosophila whole-brain connectome” by David Deutsch et al., currently available as a bioRxiv preprint (PMID: 40661468; doi: 10.1101/2025.06.10.658788).

## Repository structure

```
Supplemental_table1_neuron_annotations.csv   dsx/fru neuron annotations (public subset)
Supplemental_table2_cellType_clustering.csv  cell-type cluster assignments
data/                                        supporting data used by the MATLAB analysis
src/matlab/                                  MATLAB analysis and figure-generation scripts
src/python/                                  supporting Python plotting utilities
```

## Reproducing the figures

Figures 1, 3, and 6-9 are generated by `src/matlab/FruDsx_analysis.m`; Figure 5 (network
layout) is generated by `src/matlab/FruDsx_Network_Layout.m`. See
[`src/matlab/README.md`](src/matlab/README.md) for setup, including the external/large
data files these scripts require but that aren't tracked in this repository.

`src/python/plots.py` provides supporting plotting and clustering utilities (network
graphs, connectivity heatmaps, hierarchical clustering, Cytoscape export) used during
analysis. It includes a runnable example on synthetic data
(`python src/python/plots.py`) but does not itself reproduce a specific paper figure from
real data. See [`src/python/README.md`](src/python/README.md) for setup.

## Data availability

Small and medium-sized data files used directly by the analysis are included in this
repository (`data/`, and the `Supplemental_table*` files at the repository root). Larger
files - a published external annotation dataset and several CODEX connectome exports -
are not included; `src/matlab/README.md` documents their exact source/version and how to
obtain them.
